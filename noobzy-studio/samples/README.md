# Samples

Real input/output files produced by this build, committed as a tangible
demo (not just described). **Everything in `input/` is synthetic and
clearly labeled as such** -- color-card test clips with baked-in text
labels and a sidecar `*.events.json` of explicitly simulated event
markers, generated by `backend/tests/fixtures/make_fixture.py`. None of it
is real Roblox gameplay.

## `input/`

- `fixture_long.mp4` / `.events.json` -- 75s, 1920x1080, a simulated
  "Steal an Egg" robbery challenge (hook → 0/6 goal → chase → near-miss →
  fail → strategy → 6/6 climax → payoff).
- `fixture_short.mp4` / `.events.json` -- 27s, three simulated Special Egg
  openings (common → rare → legendary), the Shorts-only premise kept
  structurally separate from the long-form fixture per the product spec.

## `output/`

For each fixture, built by the full real pipeline (grounded timeline →
local-fallback narration → procedural SFX → multi-bus mix with measured
ducking → FFmpeg render → export):

- `*.mp4` -- the real rendered video (ffprobe-verified: `long_16x9.mp4` is
  1920x1080/75s, `short_9x16.mp4` is 1080x1920/27s), audible narration +
  SFX + ducked music baked in.
- `*_timeline.json` -- the full `TimelineDocument` that produced the
  render (the single source of truth everything else derives from).
- `*.otio` / `*.fcpxml` -- DaVinci-compatible cutlist export, round-trip
  verified by OTIO's own reader immediately after writing. **Not verified
  against the Resolve GUI itself** -- no Resolve installation exists in the
  environment this was built in.
- `*_full.srt` / `*_selective.srt` -- full word-for-word vs. selective
  kinetic-caption-keyword subtitle export.

Audio stems (`*_stem_voice.wav`, `*_stem_sfx.wav`, `*_stem_game.wav`) and
the full mixed-audio WAV are not committed here (uncompressed audio is
large and these are trivially regenerable); the command below rebuilds
everything including the stems.

## Regenerating

```bash
cd ../backend
.venv/bin/python tests/fixtures/make_fixture.py   # rewrites input/*.mp4 under tests/fixtures/generated/
# see docs/IMPLEMENTATION_STATUS.md / README.md "Try it end-to-end with curl"
# for the full pipeline, or backend/tests/test_render.py for the
# equivalent in-process Python calls that produced these files.
```
